Nusacoin ($NUX) menggunakan algoritma X11. Untuk mulai menambang, Anda perlu menyiapkan dompet (wallet), software miner, dan terhubung ke salah satu mining pool resmi di bawah ini. Berikut panduan langkah demi langkah untuk menambang menggunakan PC/Laptop (CPU atau GPU).

1

Buat Alamat Wallet Nusacoin

Sebelum mulai menambang, Anda memerlukan dompet digital untuk menampung hasil koin $NUX.

  • Buka situs resmi Nusacoin.org dan masuk ke bagian Sumber Daya.
  • Unduh aplikasi dompet sesuai perangkat Anda (Nusacoin Core Win, Nusacoin Dompet Web, atau Taobot Wallet Apk untuk Android).
  • Buat akun baru dan simpan Private Key / Seed Phrase di tempat yang aman.
  • Salin alamat penerima (Receiving Address) Nusacoin Anda (contoh format diawali nu1q...).
2

Pilih Mining Pool Resmi

Pool mining lebih direkomendasikan dibanding solo mining agar hasil lebih stabil. Gunakan salah satu pool komunitas resmi berikut:

Java Pool

pooljava.nusacoin.org

Nusa Pool

pool.nusacoin.org

Taobot Pool

pooltaobot.nusacoin.org

Catat alamat stratum URL dan isi port: 3257

3

Unduh Software Miner (Penambang)

Sesuaikan dengan hardware yang Anda miliki, unduh software penambang yang kompatibel dengan algoritma X11.

  • Jika menggunakan CPU: gunakan CPU Miner (seperti cpuminer-multi atau JayDDee cpuminer).
  • Jika menggunakan GPU: gunakan GPU Miner (seperti ccminer untuk Nvidia atau sgminer untuk AMD).
  • Sangat disarankan untuk menggunakan asic miner algoritma x11.

Tips Keamanan: Windows terkadang mendeteksi software mining sebagai 'False Positive'. Anda mungkin perlu menambahkan folder miner ke daftar pengecualian Windows Defender.

4

Konfigurasi Script Bat (Mulai Mining)

  1. Buka folder software miner Anda.
  2. Buat file teks baru (klik kanan → New → Text Document).
  3. Tuliskan kode konfigurasi di bawah ini (sesuaikan dengan data milik Anda):
cpuminer -a x11 -o stratum+tcp://pooljava.nusacoin.org:3257 -u ALAMAT_WALLET_ANDA -p x
  • Ubah PORT: 3257 sesuai angka port pool pilihan Anda.
  • Ganti ALAMAT_WALLET_ANDA dengan alamat dompet Nusacoin dari Langkah 1.
  • Klik File → Save As, ubah Save as type menjadi All Files, lalu beri nama mulai_mining.bat.
5

Jalankan Penambangan

  • Klik dua kali pada file mulai_mining.bat yang baru saja Anda buat.
  • Jendela Command Prompt (layar hitam) akan terbuka dan mulai berjalan.
  • Jika muncul tulisan "Accepted" atau "Yay!", perangkat Anda telah berhasil memecahkan algoritma dan kontribusi dihitung oleh pool.

Cara Cek Hasil Cuan

Untuk memantau seberapa banyak koin $NUX yang sudah Anda kumpulkan:

  1. Buka situs mining pool yang Anda gunakan (misalnya pooljava.nusacoin.org).
  2. Cari kolom Worker Stats atau kolom pencarian alamat dompet — atau langsung buka tab di atas.
  3. Tempelkan (paste) alamat wallet Nusacoin Anda.
  4. Anda akan melihat Hashrate serta estimasi saldo koin yang otomatis dikirim ke wallet Anda jika sudah mencapai batas minimum transfer pool.
