Verifikasi Hash Data dengan Blockchain

Unggah file data asli (.json) hasil Inject. Aplikasi menghitung SHA-256 isi file lalu mencarinya di OP_RETURN transaksi blockchain Nusacoin, lengkap dengan Tx ID dan blok.

Hash dihitung dari teks file persis seperti diunduh. Jangan menyimpan ulang atau memformat ulang file; satu karakter berbeda menghasilkan hash yang berbeda.
